# PaintPola

PyQt6 製のデスクトップペイントアプリケーション。
レイヤー・ブレンドモード・エフェクト・アニメーション・ワンクリックアクションに対応。

## 技術スタック

| 区分 | 技術 |
|------|------|
| 言語 | Python 3.13 |
| GUI | PyQt6 (Qt 6.11) |
| 画像処理 | numpy, OpenCV (cv2) |
| GIF出力 | Pillow (PIL) |
| テスト | pytest, pytest-qt |

## 起動方法

```
start.bat
```

または直接:

```
python main.py
```

## 機能一覧

### 描画ツール

| ツール | 説明 |
|--------|------|
| ペン | 丸ペン・ソフト・スプレー・マーカー・ぼかしの5種。サイズ1〜200px |
| 消しゴム | サイズ1〜300px |
| バケツ塗り | フラッドフィル。拡張/縮小 -30〜+30px、隙間閉じ 0〜20px、薄い線を拾う感度 0〜100%。参照レイヤーが白背景（不透明）の線画でも、地色を自動判別して塗れる |
| 直線 / 四角形 / 楕円 | 図形描画。枠線のみ / 塗りのみ / 枠線＋塗り |
| テキスト | キャンバス上にテキスト配置 |
| スポイト | クリックで色を取得。Alt キーで一時スポイト |
| 矩形選択 / 投げなわ | 選択モード / 変形モード切替対応。変形モード・ピボット指定もオプションから設定可能 |
| 囲み内塗りつぶし | 投げなわで囲んだ範囲内にある、線で閉じた領域だけを自動検出して塗りつぶす（クリスタ風）。マウスを離すと自動実行 |
| 移動 | レイヤー移動。矢印キー 1px、Shift+矢印 10px |
| 自由変形 | 選択範囲の移動・拡縮・回転。変形モード・ピボット指定対応 |

対称定規（左右対称描画）対応。

### 変形機能

矩形選択・投げなわ・自由変形ツールのオプションから変形モードを切り替えられる。

| モード | 説明 |
|--------|------|
| 拡縮・回転 | 8方向ハンドルによるリサイズと回転ハンドルによる回転 |
| 自由変形（パース） | 4隅を個別にドラッグして遠近感のある変形。四角形内ドラッグで全体移動。回転ハンドルにも対応 |
| メッシュ変形 | N×N 分割の格子を制御点として自由に歪ませる変形。分割数 2〜8 で調整可能。回転ハンドルにも対応 |

選択範囲なしでレイヤー全体を変形したい場合は、画像メニューの「レイヤーを変形（拡大縮小・回転）...」または変形メニューの「拡大縮小・回転（%指定）...」を使う。スライダーで % を動かすとリアルタイムでプレビューされ、OK で確定・キャンセルで元に戻る。

#### 変形ピボット（基準点）

拡縮・回転時に基準点を指定できる。

- **プリセット（9点）** — アンカーウィジェットで四隅・辺中点・中央から選択
- **任意（ドラッグ）** — キャンバス上の青い十字マーカーをドラッグで自由配置

### レイヤー

- 追加・削除・複製・並べ替え（上下移動）
- グループ（フォルダ）で一括管理。レイヤーのグループ追加・取り出しボタン対応
- ドラッグ＆ドロップによるレイヤー順序変更・グループへの移動
- 不透明度 (0〜100%)・クリッピング・参照レイヤー・表示/非表示
- ブレンドモード: 通常 / 乗算 / スクリーン / オーバーレイ / 加算
- 統合: 下に統合 / 全表示統合 / フォルダ統合（すべてUndo対応）
- アイコンベースのコンパクトUI（クリスタ風）

### レイヤーエフェクト

| エフェクト | パラメータ |
|------------|------------|
| 縁取り | サイズ、色 |
| ドロップシャドウ | 強度、X/Yオフセット、ぼかし、色 |
| グロー（発光） | 強度、サイズ、色 |
| ガウスぼかし | 強度、半径 |
| HSL調整 | 色相・彩度・明度 |

合成順: 縁取り → シャドウ → グロー → ぼかし → HSL

**ラスタライズ**（画像メニュー → レイヤーをラスタライズ）— 設定中の効果を画像ピクセルに焼き込み、エフェクト設定を無効化する。統合（下に統合等）でも同様に効果が自動で焼き込まれるため、統合後に効果が消えたり二重適用されたりしない。

### アクション

レイヤーパネルの「アクション」タブからワンクリックで実行。すべてUndo対応。ボタンが多いためパネルはスクロール表示。

| 線画ずらし（色収差） | 赤・青・黄の色ずれを生成。移動量・回転・拡縮を設定可能 |
| グロー / 発光 | 暗い背景＋色付きグローを自動セットアップ |
| 影付け | ドロップシャドウレイヤーを自動生成 |
| 背景パターン生成 | ドット・ストライプ・チェック・グラデーションなど8種（ガチャの対象外） |
| 線画色変え | 線画の色を一括変換。プリセット付き |
| ポップアウト | 白縁＋影でステッカー風に浮き出し |
| ランダムタイリング配置 | 個数・スケール・回転・重なりを指定し、レイヤーをランダムに複製配置。壁紙パターン作成等に便利。統合 / グループ出力を選択可 |
| パスに沿った連続複製 | キャンバスをクリックしてパスを描き（Enter で確定 / Backspace で1点削除 / Esc でキャンセル）、軌跡に沿って等間隔で複製配置。進行方向への自動回転に対応 |
| 紙質感グレイン | ノイズ粒子を重ねて紙のようなザラついた質感を付与。強度・粒の粗さ・合成モード（オーバーレイ / 乗算）を指定可能 |
| ずれ縁取り | 縁取りマスクをランダムにずらし・部分的に欠けさせる。「変なところに縁がつく」偶然の面白さを再現 |
| リソ風版ずれ | 線画シルエットを2〜3色の色版に分解し、各版をランダムにずらして重ねる。リソグラフ印刷の版ずれ風 |
| 切り絵コラージュ | 線で閉じた領域をランダムに検出して色紙で塗りつぶす。広い領域は自動で複数の紙片に分割して塗り分け。はみ出し・ずらしを加えて紙を貼ったような質感に。バケツツールと同じ「隙間を閉じる」「薄い線を拾う」で、隙間のある線画でも領域を検出できる |
| 線の揺らぎ | 滑らかなノイズで線を波打たせて描き直したような別テイクを作成。破線化オプション付き |
| スタンプ劣化 | 2段ノイズで線をかすれさせ、インク溜まりも追加。ゴム版画・はんこ風の質感。インク溜まりは半径の最小/最大（1〜40px）と色（線と同じ色 / 任意の色）を指定可能 |
| 等高線 | シルエット外側に一定間隔で輪郭線を何重にも生成。外側ほど薄くするフェードに対応 |
| カラーハーフトーン | 絵を印刷物のような網点ドットに変換。元画像のRGB成分を3版に分解し版ごとに角度を変えて重ねる（CMYK分版ではない）。網点の間隔・カラー / モノクロ・透明（既定） / 白地・アンチエイリアスを指定可能 |
| ディザ / レトロ減色 | 色数を落としてディザをかけ、レトロゲーム画面風に。Bayer 4x4 / 誤差拡散、階調数、ドットの粗さを指定可能。ガチャ経由ではパレットの色だけで減色 |
| クロスハッチング | 明るさに応じて斜線の密度を変え、ペン画・銅版画風の陰影に置き換える。線の間隔・太さ・重ねる段数・線の色を指定可能 |
| VHS / 走査線ノイズ | 行ずれ・ノイズ帯・走査線・ざらつきを重ね、古いビデオテープの再生画面風に |
| CRT / LED 画面 | RGBサブピクセル（CRT=縦ストライプ / LED=格子ドット）と走査線・ブルームを重ね、画面越しに見た絵にする。マスクで暗くなるぶんの明るさ・彩度補正付き |
| アンディ・ウォーホル風 | 元の絵を縮小してタイル状に並べ、コマごとに違う配色でベタ塗り。写真・カラーイラストは明るさと色相の両方で塗り分けるため髪と肌が別の色になる。線画（彩度の無い絵）は自動判別して、線で囲まれた領域ごとの塗り分けに切り替わる。分割（2×2 / 3×3 / 横3 / 縦3）・階調数・コマの間隔・輪郭線の太さ・隙間を閉じる・薄い線を拾うを指定可能。キャンバスの大きさは変わらない |
| リキテンスタイン風（アメコミ） | 太い輪郭線・少ない色数のベタ塗り・網点の3つを重ねてアメコミの1コマ風に。中間調だけを網点で表現し、最暗部はベタ・最明部は紙の白で残す。網点の間隔/色・輪郭線の太さ/色・ベタの色数・背景の白埋めを指定可能 |
| 浮世絵 / 木版画風 | 明るさと色相で版を分けて平坦に摺り、版ごとにランダムな版ズレを加える。墨線（主版）はズレさせないので絵は崩れない。線画は自動判別して、線で囲まれた領域に藍・べに等の伝統色を差す。白地に描かれた絵は白い部分を紙とみなすので、巨大な白版が絵を覆わない。版の数・版ズレ量・墨線の太さ・和紙の質感・紙の色・顔料に寄せる強さ・隙間を閉じる・薄い線を拾うを指定可能 |
| 印象派 / 油彩タッチ風 | 短い筆跡を無数に置いて油絵のタッチに置き換える。明暗の流れに沿って筆を向けるので形が保たれる。筆跡の長さ/太さ・密度・色のゆらぎを指定可能 |
| ステンドグラス風 | 画面を不定形のガラス片に分割し、各片を1色で塗って鉛線で囲む。片を採用する被覆率は絵の密度に応じて決まるので、線画のように疎な絵でもガラスが消えない。ガラス片の大きさ・鉛線の太さ/色・透過光の強さ・背景もガラスにするかを指定可能 |
| ブループリント / 設計図風 | 輪郭だけを抜き出して青地に白線で描き、方眼（細線＋一定間隔の太線）を敷いて図面風に。地/線の色・線の太さ・方眼の間隔・太線の間隔・かすれを指定可能 |
| 銅版画 / エッチング風 | 明暗を細かい彫り線の密度に置き換える。線を波打たせて手彫りらしい揺らぎを出し、最暗部はベタで潰す。線の間隔・彫りの段数・揺らぎ・インク/紙の色・紙の質感を指定可能 |

### 線画抽出

画像メニューの「線画抽出...」で、写真やカラーイラストから線画レイヤーを作る。リアルタイムプレビュー付き。

| 設定 | 内容 |
|------|------|
| 抽出方式：しきい値 | 指定した明るさより暗いピクセルを線とする。きれいにスキャンした線画・デジタルイラスト向け |
| 抽出方式：自動 | 周囲の平均より暗いピクセルを線とする（適応的しきい値）。**紙を写真で撮ったとき向け**。照明ムラで片側が影になっていても、影を拾わずに線だけを抽出できる |
| 感度 / 線を探す範囲 | 自動モードの調整。感度を上げると濃い線だけ、下げると薄い線も拾う。範囲は線を探す近傍の広さ(px) |
| 彩度を落とす | 色かぶりを抑える。ただし彩度を下げることは色を白に寄せることなので、色ペンの線はかえって薄くなる（既定 0） |
| コントラスト / 明るさ | 抽出前の下ごしらえ。薄い線が拾えないときは「明るさ」を下げるとしきい値の下に入る |
| ノイズ除去 | 紙の繊維やセンサーノイズによる孤立した黒点を消す(px)。線は連結しているので残る |

抽出結果は背景透過・線は黒の「線画」レイヤーとして追加される。

### キャンバス

- デフォルトサイズ: 2500 x 2500px
- 起動時は自動でキャンバス全体が画面に収まるズームで表示（「全体表示」相当）
- ズーム: マウスホイール（5%〜500%）
- パン: 中ボタンドラッグ / Space+ドラッグ
- 回転: ナビゲーターの回転ボタン（左右回転・リセット）
- 左右反転表示
- サイズ変更: 9点アンカー + リアルタイムプレビュー
- 透明チェッカーボード: 背景がない部分にグレー×白の格子を表示

### ナビゲーター

- キャンバス全体の縮小プレビュー
- 赤枠で現在の表示範囲を表示。ドラッグでスクロール
- ズームイン/アウト・リセットボタン
- 回転・反転の表示にも対応

### アニメーション（パラパラ漫画）

メニュー → アニメーションモードで有効化。

- フレームの追加・差し替え・削除・順序入れ替え
- 再生/停止（FPS指定）
- オニオンスキン（前フレーム半透明表示、枚数指定可）
- プレビュー窓（フローティング再生確認）
- GIF書き出し (Pillow)

| フランスの伝統色 | 45 | ルージュ・アジュール・ラヴァンド 等 |

| パステル | 24 | 淡色系 |
| 肌色・人物 | 18 | スキントーン・メイクカラー |
| 自然・風景 | 24 | 空色・紅葉・海原 等 |

- 右クリックで現在色を上書き登録、「現在色を登録」ボタンで追加も可能

### UI

- **ツールアイコン** — 各ボタンにアイコン付きで視認性向上
- **ツールショートカット** — ボタンのツールチップにショートカットキーを表示（例：「ペン [P]」「消しゴム [E]」）。キャンバスにフォーカスがある状態でキーを押すと即時切り替え
- **カラーヒストリー** — ツールバーに最大10色のカラー履歴スウォッチを常時表示。クリックで即時切り替え
- **ツール別カーソル** — ペン→十字、バケツ→バケツ型、スポイト→スポイト型 等
- **テーマ切替** — デフォルト / ダークモード / Windows 95風 / 16bitレトロ / パステル / Google Material。選択したテーマは自動保存され、次回起動時も維持される
- **ステータスバー** — カーソル座標、ズーム倍率、キャンバスサイズ。パスピックモード中は操作ガイドを表示
- **リサイズ可能パネル** — 右パネル（ナビゲーター / レイヤー）がスプリッターで自由にサイズ調整可能

### ファイル形式

| 形式 | 説明 |
|------|------|
| .pola | 独自形式（ZIP）。全レイヤー・エフェクト設定を保存。読み込み時にバリデーション実施 |
| PNG / JPEG / BMP | 全レイヤー統合画像として書き出し。画像ファイルは新規キャンバスとしても、既存レイヤーとしても読み込み可能 |
| GIF | アニメーションフレームを書き出し |

### メニュー

| メニュー | 主な項目 |
|----------|----------|
| ファイル | 新規 / 開く / 保存 / 名前を付けて保存 / PNGとして書き出し(PNG/JPEG/BMP) / 画像をレイヤーとして追加 / 終了 |
| 編集 | 元に戻す / やり直し / コピー / 切り取り / 貼り付け / 削除 / 全選択 / イラストを選択 / 選択を反転 / 選択解除 |
| 画像 | キャンバスサイズ変更 / 統合系 / フォルダを結合 / レイヤーをラスタライズ / レイヤーを変形（拡大縮小・回転）... / 線画抽出... |
| 変形 | 変形モード切替 / 拡大縮小・回転（%指定）... |
| フィルター | ぼかし (ガウス)... / ゴミ取り...（面積指定で孤立した小さな塊を透明化。リアルタイムプレビュー対応） |
| 表示 | ズーム / 回転 / 左右反転 / テーマ切替 |

**未保存の変更の保護** — 未保存の変更があるとウィンドウタイトルに `*` 印が付く。その状態で「新規作成」「開く」「アプリ終了」をしようとすると、「保存する / 保存しない / キャンセル」の確認ダイアログが出て、その場で保存できる。

### セキュリティ

.pola ファイル読み込み時の安全対策:

- キャンバスサイズ・エフェクトパラメータの範囲クランプ
- ZIPファイルサイズ・展開後サイズの上限チェック（Zipボム対策）
- パストラバーサル防止（ファイル名サニタイズ）
- 画像読み込み失敗の検出
- JSON型検証・レイヤー数上限

### 内部構造

**ブラシエンジン** — `BrushBase` 継承の5種（丸ペン / ソフト / スプレー / マーカー / ぼかし）。Canvas は `stroke_to()` だけを呼ぶ。

**エフェクト処理** — `Layer.image_with_effects()` で numpy/cv2 を使い合成。縁取り(膨張) → シャドウ(ぼかし+オフセット) → グロー(膨張+ぼかし+着色) → ブラー → HSL。

**変形エンジン** — 3つのモードを統一的に管理:
- 拡縮・回転: QTransform ベースの行列変換
- 自由変形（パース）: `cv2.getPerspectiveTransform` で4隅の射影変換
- メッシュ変形: N×N 分割した格子の各セルに `cv2.warpPerspective` を適用して合成

**履歴システム** — タグ付きタプルで2種類を管理:
- `("pixel", layer_id, QImage, offset_x, offset_y)` — 描画前の画像コピーと、そのときのレイヤー位置
- `("structure", snapshot)` — 全レイヤーの再帰的スナップショット

履歴1件はレイヤー画像を丸ごとコピーするため、2500x2500 では1件あたり約25MBになる。
件数だけで制限すると 50 件で 1.2GB を超えてメモリ不足で落ちるため、件数と総メモリ量の両方で打ち切る:

| 定数 | 値 | 意味 |
|------|----|------|
| `HISTORY_LIMIT` | 50 | 最大件数 |
| `HISTORY_MEMORY_LIMIT` | 512MB | 履歴全体の合計画像バイト数の上限 |
| `HISTORY_MIN_ENTRIES` | 5 | メモリ超過時でも必ず残す件数 |

小さいキャンバス（800x600 等）ではメモリ上限に当たらないため、従来どおり50件フルに保持される。

**.pola 形式** — ZIP内に `meta.json`（レイヤー構成・エフェクト設定）+ 各レイヤーPNG。読み込み時にサイズ・パラメータ・パスのバリデーションを実施。
